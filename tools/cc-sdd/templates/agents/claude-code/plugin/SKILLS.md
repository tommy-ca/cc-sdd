# Plugin Skills Inventory

This plugin ships the shared Kiro skills set. Commands are thin wrappers that map 1:1 to these skills.

## Command-mapped skills
- spec-init -> kiro-spec-init
- spec-requirements -> kiro-spec-requirements
- spec-design -> kiro-spec-design
- spec-tasks -> kiro-spec-tasks
- spec-impl -> kiro-spec-impl
- spec-status -> kiro-spec-status
- validate-gap -> kiro-validate-gap
- validate-design -> kiro-validate-design
- validate-impl -> kiro-validate-impl
- steering -> kiro-steering
- steering-custom -> kiro-steering-custom

## Skills without Claude Code command wrappers
- kiro-spec-quick (Claude Code Agent-only workflow)
