# Kiro SDD Dev Marketplace

Local marketplace for the `kiro-sdd` Claude Code plugin.

## Add marketplace
From repo root:
```
/plugin marketplace add .kiro/marketplace
```

## Install plugin
```
/plugin install kiro-sdd@kiro-sdd-marketplace
```
Restart Claude Code after installation.

## Contains
- `.claude-plugin/marketplace.json` — marketplace manifest pointing to `../plugins/kiro-sdd`
